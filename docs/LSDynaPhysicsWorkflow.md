# LS-DYNA 滑坡建模、数据导出与物理验证

本项目目前提供的是 **LS-DYNA 数据接入与真实时间回放流程**。用户尚未提供此次滑坡的 LS-DYNA 模型或计算结果，因此不能把接入测试、解析样例或现有动画称为已经完成的 LS-DYNA 山体滑坡仿真。具体导入与 Unity 操作见 [LS-DYNA 接入说明](LSDyna.md)。

降雨诱发的实际滑坡还需要滑前地形、地层与基岩、前期和事件降雨、初始水分、渗流孔压及稳定性分析。项目新增的[降雨场地准备工具及严格格式](RainfallCasePreparation.md)可以生成**仅含几何的**三维实体网格、分区降雨时段和审计报告；它不运行非饱和入渗、LS-DYNA 或失稳求解。任何 `case_report.json` 都标为 `prepared-not-solved`，不能替代现场或求解验证。

项目原有的 151 帧来源于 RAMMS；原有后阶段程序动画也不是 LS-DYNA 求解结果。它们可以保留原来源标签用于展示，但不能改名为 LS-DYNA 数据，不能用于证明本次 LS-DYNA 模型符合实际物理规律。

## 1. 当前接入范围

本次流程接收固定节点集合、固定表面三角形拓扑的时序数据。每个时刻需要节点 ID、变形后的绝对坐标、速度与节点质量；节点位置驱动 Unity 网格，求解器时间决定播放时刻。坐标、速度、质量和时间统一转换为 SI，再映射到 Unity 局部坐标。仅有表面节点的数据可以展示表面运动，却不能据此计算整个滑体的质量、动量和动能；整体诊断需要覆盖被审计物体的全部质量。

当前流程不实现 LS-DYNA 求解器，也不直接求解本构、接触或渗流。Unity 不应再次对已求解的节点施加重力、摩擦或刚体积分，否则会把第二套运动覆盖到结果上。显示插值只连接输出状态，不会提高求解精度，也不提供新的碰撞或破坏预测。

当前回放分别对位置和导出速度做线性插值。速度颜色表示导出速度的插值，不保证等于两输出状态之间渲染位置曲线的瞬时导数；加速、冲击或弯曲轨迹应增加求解输出密度，并在原始状态时刻进行定量对照。

当前固定拓扑流程不能忠实播放单元侵蚀、节点删除、重网格、自适应拓扑或自动生成的新断裂面。已有彼此独立的块体若节点和表面连接始终不变，可以表示其运动；这不等于实现真实碎裂。若实际算例使用上述变化机制，应先扩展帧级拓扑与质量/能量审计，不能将删除前的固定表面继续拉伸来冒充破碎结果。

## 2. 先确定力学问题，再选择材料与单元

连续体的质量和动量守恒应由求解器满足：

```text
Dρ/Dt + ρ ∇·v = 0
ρ Dv/Dt = ∇·σ + ρ g
```

其中 `ρ` 是密度，`v` 是速度，`σ` 是总 Cauchy 应力张量，`g` 是重力加速度向量，`D/Dt` 是物质导数。外部牵引、接触、支承和可能的流固作用还需进入相应边界条件或体力项。节点位移曲线平滑不代表这些方程已被满足。

岩土滑坡需区分完整岩体、节理岩体、覆盖土、弱夹层以及碎屑堆积体。应先用地形、地质分层、滑面及地下水资料确定机制，再选择适用的连续体、块体接触或大变形离散方法。不得仅因为某个材料卡容易运行就把不同材料统一为一种软弹性体。

对于适用有效应力 Mohr–Coulomb 近似的材料，采用法向压应力为正的约定时：

```text
τf = c′ + (σn - u) tan φ′
```

`c′` 是有效黏聚力，`φ′` 是有效内摩擦角，`σn` 是总法向应力，`u` 是孔隙水压力。提高孔压会降低有效法向应力和抗剪强度。该式是适用条件下的强度描述，尚不包含弹性、流动法则、剪胀、峰后软化、抗拉截断和断裂能；不能将它作为所有滑坡的完整材料模型。非饱和土、强节理控制的岩坡、速率效应显著或强流固耦合问题需要相应扩展。Ansys 的 [Geomechanics 材料参考](https://ansyshelp.ansys.com/public/Views/Secured/corp/v252/en/ans_mat/mat_geomechanics.html) 与 [有效应力及孔流耦合说明](https://ansyshelp.ansys.com/public/Views/Secured/corp/v242/en/ans_cou/Hlp_G_COU_porefluiddiffstruct.html) 可用于理解这些物理概念；这两份 Mechanical APDL 文档不是 LS-DYNA 材料卡语法，不能直接把其中命令粘贴到 `.k` 文件。

首次求解至少需要以下可追溯输入：

| 输入 | 需要记录的证据与用途 |
| --- | --- |
| 地形、滑体、滑面 | DEM/测绘日期、坐标基准、精度、滑体厚度与体积、节理/弱层位置，区分渲染地形与计算边界 |
| 密度和刚度 | 现场或室内试验来源、含水状态、密度、弹性或体积/剪切刚度及其单位，核查计算总质量 |
| 强度和变形 | 排水条件一致的三轴/直剪试验、峰值及残余强度、剪胀、拉伸破坏或软化资料；记录参数范围和标定过程 |
| 坡底与块间接触 | 对应材料配对的摩擦、可能的黏结/脱开依据、初始间隙及接触几何 |
| 地下水与触发 | 水位/孔压、降雨或地震等时间历程、滑面强度变化的独立依据，不能按动画观感调节触发时间 |
| 初始状态与边界 | 初始应力、重力方向、地基约束、计算域大小、预平衡结束条件、释放或加载规则 |
| 版本与数值设置 | LS-DYNA 可执行文件版本/修订、SMP/MPP、精度、单元/材料/接触形式、时间步及质量缩放设置 |

这里不给出冒充实测值的密度、黏聚力、摩擦角或黏性参数，也不提供未经求解核实的山体 `.k` 卡。材料参数缺失时应明确标为待测、待标定或敏感性区间。

## 3. 重力预平衡与启动机制

真实山体在失稳前通常已经承受自重。直接把无应力网格放进重力场，会产生与真实触发无关的瞬态振动。应先建立重力与初始应力平衡，再运行滑移过程，并明确两阶段的时间原点。

LS-DYNA 支持通过 `*LOAD_BODY_X/Y/Z` 施加相应方向的重力，可按问题采用显式/隐式动态松弛或独立的静力预加载。`*CONTROL_DYNAMIC_RELAXATION`、`*DEFINE_CURVE` 和必要的隐式控制可组织预加载；`*DATABASE_BINARY_D3DRLF` 可记录松弛阶段。具体字段、相位与重启动方式必须按所用版本核实。参见官方支持资料 [Gravity Load](https://www.dynasupport.com/howtos/general/gravity-load) 和 [Implicit Dynamic Relaxation](https://www.dynasupport.com/howtos/implicit/implicit-dynamic-relaxation)。

预平衡验收应包括残余不平衡力、位移继续变化量、动能衰减及支承反力/总重的对照，并确认预加载阶段没有已经发生不应有的塑性流动。阈值由模型尺度和研究目标确定并保存，不照搬某个通用百分比。为预平衡使用的数值阻尼，需要在滑移阶段撤除或以物理依据保留；否则可能把滑坡速度、到达时间和堆积范围人为减小。

触发阶段应来自明确工况，例如孔压上升、弱层强度退化、开挖卸载或地震输入。若把所有节点人为赋予下坡速度，得到的是该初速度条件下的运动，不能据此证明山体自然失稳。

## 4. 接触摩擦与能量解释

在简化的干摩擦接触中，法向反力限制穿透，切向摩擦反对相对滑动。滑动状态下摩擦力幅值约为 `μ N`，静止状态则受静摩擦极限约束。材料内部的 `φ′` 与坡底/块间接触的 `μ` 不是可互换的同一参数。

LS-DYNA 的相应 `*CONTACT...` 选项使用 `FS`、`FD` 等控制摩擦，静/动摩擦过渡与 `DC` 等设置有关；适用接触算法与可用字段依版本和单元形式而异。先检查初始穿透、接触面方向、罚刚度、网格尺度以及重复接触，再做摩擦敏感性计算。参见 [Contact Modeling in LS-DYNA](https://www.dynasupport.com/tutorial/ls-dyna-users-guide/contact-modeling-in-ls-dyna)。不要通过增大摩擦或阻尼掩盖不稳定网格。

在节点质量恒定、全体质量均被计入、重力场均匀且坐标系惯性的条件下，可从输出计算：

```text
M = Σ mi
p = Σ mi vi
K = 1/2 Σ mi |vi|²
U_g = -Σ mi g·(xi - xref)
```

`xref` 是固定势能参考点，只影响势能零点。节点质量必须来自求解器或经过核对的质量集总，包含分析中实际使用的质量；不能给每个表面顶点随意分配相同质量再宣称得到整体动能。质量缩放、侵蚀、流入流出或节点集合变化会改变上述审计条件。

当前接口要求每个节点的质量为恒定正值，并按平移自由度的集总质量计算 `K`；不能为了通过导入给零质量节点虚构质量。梁/壳或刚体的额外转动自由度、某些选择性质量缩放形成的非对角质量矩阵等可能无法用该标量节点质量表达。此时节点动能不能替代求解器动能，需调整导出范围/表示方式并独立核对求解器能量账本。

`K + U_g` 不是一般可变形滑坡的全部能量。弹性储能、塑性功、摩擦耗散、阻尼、接触罚能、小时玻璃能以及外部加载都可能参与平衡。动量也不应被要求恒定：重力、坡底反力和边界作用使系统动量变化；只有核对完整外力冲量后才可讨论动量残差。

LS-DYNA 的 `GLSTAT` 能量账本应按实际启用项与版本解释，并核对其总能量与初始能量及外力功的关系。若重力已作为体力计入外力功，就不能再把势能下降作为另一份输入能量重复加入同一账本。可另建 `K + U_g` 诊断，但必须把重力从该账本的外力功中剔除，并补齐其他储能/耗散项。`GLSTAT`、`MATSUM` 与后处理的简化全局曲线也可能包含不同项；参见 [Total Energy](https://www.dynasupport.com/howtos/general/total-energy)。

`SLEOUT` 的摩擦能已经包含在接触双方能量之和内，而 `GLSTAT` 的 sliding energy 汇总接触能。因此不能再把摩擦能直接加到已含它的 sliding energy 上；较大的正接触能可能包含真实摩擦耗散，突发负接触能则需要检查穿透和接触算法。参见 [Ansys Contact Energy](https://lsdyna.ansys.com/contact-energy/)。

下表是需要在所用版本手册中确认的输出关键词与用途，不是可直接执行的完整求解卡。先在一个小算例中确认输出内容，再提交大型山体模型。

| 关键词/文件 | 用途与注意事项 |

| `*DATABASE_MATSUM` | 分部件/材料质量及能量诊断，辅助定位异常来源 |

输出依据见 Ansys 的 [Database Output Settings](https://ansyshelp.ansys.com/public/Views/Secured/corp/v252/en/lsdyna_ug/exd_ag_lsdyna_db_output_settings.html)、[节点历史输出说明](https://innovationspace.ansys.com/forum/forums/topic/directly-save-the-response-of-a-node/) 和 [LS-DYNA R13 Keyword Manual, Volume I](https://www.dynasupport.com/manuals/ls-dyna-manuals/ls-dyna_manual_volume_i_r13.pdf)。Workbench 文档、R13 手册和支持文章对应不同版本；实际生产算例以安装版本的 Keyword/Theory Manual 与 release notes 为准。

推荐导出路径：

1. 在 LS-PrePost 中先检查完整 `d3plot` 文件族能否正常打开、状态时间是否连续、滑体质量/几何是否正确。
2. 使用 LS-PrePost 支持的导出能力，或经核对的求解结果读取器，提取原始节点 ID、初始坐标、每状态的位移或绝对坐标、速度及质量。官方 [Formatted Output](https://lsdyna.ansys.com/output/) 说明模型/位移导出；[plot2nodout](https://lsdyna.ansys.com/dm-plot2nodout/) 可将指定节点的 `d3plot` 历史提取为 `nodout`。这些工具本身不保证一次操作就生成本项目要求的 CSV。
3. 若导出的是位移，先用相同节点 ID 的初始坐标重建 `x(t) = x0 + u(t)`；不要把位移当作绝对位置。确认速度来自同一坐标系和同一状态时刻。若只能差分估计速度，应明确记录估计方法和误差，不能把它冒充求解器速度。
4. 组织为项目约定的全节点 CSV；另由计算表面连接导出固定三角形顶点 ID。对四边形进行一次固定划分，保留一致绕序；不能每帧重新按顶点顺序拼面。
5. 执行项目转换和数据审计，将总质量、包围盒、选定节点位置/速度与 LS-PrePost 对照；再按同一时间点对照 Unity 画面。原始结果和求解日志应独立归档，CSV 与播放文件只是派生物。

## 6. 单位、坐标与时间不能靠画面猜测

LS-DYNA 要求一致的单位体系，不会自动把输入数字解释为 SI。至少声明长度、质量、时间三个基准及派生量，并将转换比例写入接入元数据。若 `L`、`M`、`T` 分别是原始单位到米、千克、秒的比例，则：

```text
x_SI = L x_source          t_SI = T t_source
v_SI = (L/T) v_source      m_SI = M m_source
g_SI = (L/T²) g_source     E_SI = (M L²/T²) E_source
```

例如一致的 `mm–ms–kg` 系统里，`1 mm/ms = 1 m/s`，而 `9.81 m/s² = 0.00981 mm/ms²`；不能因为速度换算系数恰好为 1，就省略位置和时间换算。单位原则见 [Consistent Units](https://www.dynasupport.com/howtos/general/consistent-units)。

用明确的坐标变换统一位置、速度、重力：位置先减去固定原点再变换，速度和重力只进行向量变换，不加平移。源数据如以 Z 轴向上，必须显式映射到 Unity 的 Y 轴向上；改变坐标手性时还要检查三角形绕序和法线。大地坐标宜先减去局部原点，避免将很大的绝对坐标直接存入 float32 顶点造成精度损失。变换后的长度尺度应与场景地形核对，不能靠随意缩放滑体来掩盖单位错误。

动画使用状态时间插值，`1×` 表示每过一秒播放一秒仿真时间；慢放改变观看速度，不改写仿真时间、速度或加速度。非等间隔输出必须保留原时间戳，不能按固定“每帧若干秒”播放。跨越冲击或快速失稳的稀疏输出可能漏掉峰值，插值无法恢复被漏掉的物理过程。

## 7. 数值可信度与现实吻合度分别验收

建议至少做三档网格、时间步控制及输出间隔的敏感性对照，观察滑移启动时间、质心轨迹、最大速度、到达时间、堆积范围和关键能量项。每次只改变明确的数值因素并记录误差指标；若使用软化模型，还需检查网格依赖与适用的正则化/断裂能处理。数值收敛不等于材料模型正确。

质量缩放通过增加非物理质量放大稳定时间步，会改变惯性。必须记录全局及关键部件的加质量、其发生时间/位置，并与更少或无质量缩放的结果比较，不能仅凭“新增质量很少”断言对启动和峰值速度无影响。官方建议通过 `GLSTAT`、`MATSUM` 追踪并进行敏感性核对，见 [Mass Scaling](https://www.dynasupport.com/howtos/general/mass-scaling)。

欠积分单元可能出现非物理小时玻璃模式。检查形态、网格质量和小时玻璃能时，应按部件分析，避免全局总量掩盖局部异常。支持资料给出的“相对峰值内能低于约 10%”只是经验性排查参考；在内能很小的近刚体滑移中该比例可能失去意义，不能当作通用物理通过线。见 [Hourglass](https://www.dynasupport.com/howtos/element/hourglass)。

交付真实算例前应形成三层证据：

| 层级 | 必须提供的记录 | 能支持的结论 |
| --- | --- | --- |
| 数据接入正确 | 单位/轴向/原点、节点对应、时间戳、固定拓扑、数据审计与选点对照 | 播放文件忠实表达已导出的状态 |
| 数值求解可信 | 正常结束日志、初始平衡、质量和能量账本、接触检查、网格/时间步/质量缩放敏感性 | 该数值模型的解在明确误差范围内稳定且自洽 |
| 实际滑坡验证 | 实测或独立资料中的速度/到达时间/滑程/堆积厚度与范围，标定集与验证集区分、参数不确定性 | 在规定场地、工况与误差范围内的现实适用性 |

接入工具的通过报告只能支持第一层及已实现的有限运动学诊断，不能代替求解器的完整力学审计或现场验证。没有测量证据时，结果应标为“给定假设下的预测”，明确参数范围与未验证内容。

## 8. 解析斜面夹具只检验接入链路

项目的解析测试设定为：刚性物体从静止沿足够长的固定平直斜面向下滑动；坡角 `θ = 30°`，滑动摩擦系数 `μ = 0.3`，`g = 9.81 m/s²`。忽略转动、空气阻力、形变和其他加载，并假定静摩擦不会阻止启动。此设定不是 Hunnedalen 的实测材料参数，也不是 LS-DYNA 输出。

沿坡向下为正时：

```text
N = m g cos θ
a = g (sin θ - μ cos θ) = 2.3562872367 m/s²
s(t) = 1/2 a t²
v(t) = a t
Δh = -s sin θ
D_friction = μ m g cos θ · s
Δ(K + U_g) = -D_friction
```

该测试检验时间单位、坐标变换、位移/速度量纲及机械能损失的符号和数量级。这里机械能下降等于摩擦功，是上述理想模型在恒定质量、无其他储能/耗散和外部输入条件下的结论。它不能推广为“真实滑坡的 `K + U_g` 必须只按摩擦衰减”。后续应再用同一斜面条件运行真正的 LS-DYNA 小算例，对照解析解，然后才扩大到有实测参数与地形的滑坡模型。
